# Генерация иконок для PWA

Иконки для PWA созданы в стиле кнопки "П!" - круглые, с светло-голубым фоном (#87ceeb) и текстом "П!" в шрифте Amatic SC Bold.

## Способ 1: Использование Node.js скрипта (рекомендуется)

1. Установите зависимости:
```bash
npm install sharp
```

2. Запустите скрипт:
```bash
node scripts/generate-icons.js
```

Иконки будут созданы в папке `public/`:
- `icon-32x32.png` (favicon)
- `apple-icon-180x180.png` (Apple Touch Icon)
- `icon-192x192.png` (PWA)
- `icon-512x512.png` (PWA)

## Способ 2: Использование HTML генератора в браузере

1. Откройте файл `scripts/generate-icons.html` в браузере
2. Нажмите кнопки "Скачать" для каждого размера
3. Сохраните скачанные файлы в папку `public/`

## Способ 3: Ручное создание

Если у вас есть графический редактор, создайте иконки вручную:
- Размер: 192x192 и 512x512 пикселей
- Форма: круг
- Фон: #87ceeb (светло-голубой)
- Текст: "П!" в шрифте Amatic SC Bold, цвет #1f2937
- Текст должен быть по центру

## Проверка

После создания иконок убедитесь, что они доступны по путям:
- `/icon-32x32.png` (favicon)
- `/apple-icon-180x180.png` (Apple Touch Icon)
- `/icon-192x192.png` (PWA)
- `/icon-512x512.png` (PWA)

Эти пути указаны в:
- `app/layout.tsx` (метаданные для favicon и Apple Touch Icon)
- `public/manifest.json` (PWA иконки)
