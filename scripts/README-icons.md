# Иконка Dostavita

Векторный оригинал: `public/icon.svg`. Легковой автомобиль, молния и линии движения обозначают быструю доставку. Цвета: голубой #87ceeb, тёмно-синий #102c42, оранжевый #ff6a3d.

`npm run generate-icons` создаёт PNG для favicon, Apple и PWA из SVG без зависимости от шрифтов. Если рядом есть Android-проект, обновляет его launcher-иконки. Идентификатор Android-приложения сохраняется, чтобы не нарушать обновление уже установленных APK.

Будущий основной домен — https://dostavita.by. Подключение DNS и адресов авторизации выполняется после регистрации домена.
