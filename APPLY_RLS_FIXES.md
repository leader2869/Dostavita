# Инструкция по применению исправлений RLS рекурсии

## Проблема
Ошибка: `infinite recursion detected in policy for relation "profiles"`
Заказы не отображаются, обновление местоположения не работает.

## Решение
Примените следующие миграции в Supabase в указанном порядке:

### 1. Миграция 062: Разрешить водителям видеть отмененные заказы
**Файл:** `supabase/migrations/062_allow_drivers_view_cancelled_orders.sql`
- Исправлена рекурсия в политике для отмененных заказов
- Использует `check_driver_role` вместо прямого SELECT из profiles

### 2. Миграция 063: Исправление рекурсии в политике driver_locations
**Файл:** `supabase/migrations/063_fix_driver_locations_rls_recursion.sql`
- Исправляет рекурсию при обновлении местоположения водителя
- Использует `is_driver_organization` вместо прямого SELECT из profiles

### 3. Миграция 064: Исправление всех оставшихся рекурсий
**Файл:** `supabase/migrations/064_fix_all_rls_recursions.sql`
- Исправляет рекурсию в политике `order_rejections`
- Использует `check_user_role` вместо прямого SELECT из profiles

## Как применить

1. Откройте Supabase Dashboard
2. Перейдите в SQL Editor
3. Примените миграции в порядке: 062 → 063 → 064
4. После применения обновите страницу в браузере

## Проверка

После применения миграций:
- ✅ Заказы должны отображаться
- ✅ Обновление местоположения должно работать
- ✅ Отмененные заказы должны быть видны водителям
- ✅ Ошибка "infinite recursion" должна исчезнуть
