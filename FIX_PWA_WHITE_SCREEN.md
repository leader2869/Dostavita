# Решение проблемы белого экрана в PWA

## Проблема
После сохранения страницы на экран домой (как веб-приложение/PWA) открывается белый экран. При включении VPN все работает.

## Причины

1. **Supabase блокирует запросы** - домен PWA не добавлен в настройки Supabase
2. **Переменные окружения не загружаются** - в PWA контексте переменные могут не быть доступны
3. **CORS проблемы** - Supabase не разрешает запросы с домена PWA
4. **Сетевые ограничения** - возможно, провайдер блокирует доступ к Supabase (часто в Беларуси)

## Решение

### Шаг 1: Добавить домен в Supabase (ОБЯЗАТЕЛЬНО!)

1. Откройте **Supabase Dashboard** → **Settings** → **API**
2. В разделе **URL Configuration**:
   - **Site URL**: добавьте `https://prosto.of.by` (если еще не добавлен)
   - Также добавьте домен, с которого открывается PWA
3. В разделе **Additional Redirect URLs**:
   - Добавьте: `https://prosto.of.by/**`
   - Добавьте: `https://dostavita.vercel.app/**` (если используете)
4. В разделе **CORS** (если есть в настройках):
   - Добавьте домен: `https://prosto.of.by`
   - Добавьте: `https://dostavita.vercel.app`
   - Для локальной разработки: `http://localhost:3000`

**Если в консоли ошибка «Fetch API cannot load ... due to access control checks»** — это CORS: запросы к Supabase блокируются браузером, потому что ваш текущий origin (адрес сайта в строке браузера) не в списке разрешённых. Добавьте этот origin в Supabase Dashboard → Settings → API (Site URL и при необходимости раздел с CORS / дополнительными URL).

### Шаг 2: Проверить переменные окружения в Vercel

Убедитесь, что переменные окружения правильно настроены в Vercel:
- `NEXT_PUBLIC_SUPABASE_URL` - должен быть полный URL (например, `https://xxx.supabase.co`)
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` - должен быть правильный ключ

### Шаг 3: Проверить доступность Supabase

Если VPN помогает, возможно:
- Провайдер блокирует доступ к Supabase
- Нужно использовать VPN или другой DNS

### Шаг 4: Добавить обработку ошибок (уже добавлено)

В коде уже добавлена обработка ошибок подключения:
- Проверка переменных окружения
- Таймаут для запросов
- Информативные сообщения об ошибках

## Временное решение

Если проблема связана с сетью/провайдером:
- Используйте VPN (как вы уже делаете)
- Или проверьте настройки файрвола/провайдера
- Попробуйте другой DNS (например, Google DNS: 8.8.8.8)

## Проверка

1. Откройте PWA без VPN
2. Откройте DevTools (F12) → Console
3. Проверьте ошибки:

   - Ошибки загрузки переменных окружения
