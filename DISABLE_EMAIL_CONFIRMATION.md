# Отключение подтверждения email в Supabase

## Способ 1: Подтвердить email для всех пользователей через SQL (рекомендуется)

Это самый простой и надежный способ - просто подтверждаем email для всех пользователей.

1. Откройте [Supabase Dashboard](https://app.supabase.com)
2. Перейдите в **SQL Editor**
3. Выполните миграцию `007_confirm_all_emails.sql` или скопируйте и выполните:

```sql
-- Подтверждаем email для всех пользователей
UPDATE auth.users 
SET email_confirmed_at = NOW() 
WHERE email_confirmed_at IS NULL;

-- Примечание: confirmed_at - это generated column, обновляется автоматически
```

После выполнения этого скрипта все пользователи смогут входить без подтверждения email.

## Способ 2: Через Supabase Dashboard (если доступно)

Интерфейс может отличаться в зависимости от версии Supabase:

1. Откройте [Supabase Dashboard](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в **Settings** (Настройки) → **Authentication**
4. Найдите раздел **Email Auth** или **Email Settings**
5. Ищите опцию **"Enable email confirmations"** или **"Require email confirmation"**
6. Если найдете - отключите её
7. Сохраните изменения

**Примечание:** Если такой опции нет, используйте Способ 1 (SQL скрипт).

## Способ 3: Через Management API (автоматизация)

Если нужно автоматизировать, используйте Management API (требуется service role key).

## После подтверждения email через SQL:

1. Все существующие пользователи смогут входить сразу
2. Новые пользователи - зависит от настроек Supabase
3. Если новые пользователи все еще не могут войти, выполните скрипт снова после регистрации

**Важно:** Этот скрипт подтверждает email для существующих пользователей. Для новых пользователей может потребоваться выполнить скрипт снова или настроить автоматическое подтверждение через триггер.

## Важно:

- Отключение подтверждения email снижает безопасность
- Используйте это только для разработки и тестирования
- В production рекомендуется оставить подтверждение email включенным

## Способ 4: Автоматическое подтверждение для новых пользователей

Для автоматического подтверждения email всех новых пользователей выполните миграцию `008_auto_confirm_new_users.sql`:

1. Откройте Supabase Dashboard → SQL Editor
2. Выполните миграцию `008_auto_confirm_new_users.sql`

Этот скрипт:
- Создает триггер, который автоматически подтверждает email при регистрации
- Подтверждает email для всех существующих пользователей

## Проверка:

После выполнения SQL скриптов попробуйте:
1. Войти с существующим пользователем (должно работать)
2. Зарегистрировать нового пользователя
3. Сразу войти с новым пользователем (должно работать, если применена миграция 008)
