# Обзор статусов заказов по ролям

## Все возможные статусы заказов в системе:

1. **`searching_courier`** - Ищем курьера
2. **`courier_coming`** - Курьер едет к вам / Еду за посылкой
3. **`courier_delivering`** - Курьер доставляет заказ / Доставляю заказ
4. **`completed`** - Заказ завершен
5. **`cancelled`** - Отменен

---

## РОЛЬ: КЛИЕНТ (client)

### Где отображаются статусы:
- Главная страница (`/dashboard/client`)
- Список заказов (`/dashboard/client/orders`)
- Детали заказа (`/dashboard/client/orders/[id]`)

### Отображение статусов:

| Статус | Текст | Цвет | Мигает |
|--------|-------|------|--------|
| `searching_courier` | "Ищем курьера" | Желтый (`text-yellow-400 bg-yellow-400/20 border-yellow-400/50`) | ✅ Да |
| `courier_coming` | "Курьер едет к вам" | Синий (`text-blue-400 bg-blue-400/20 border-blue-400/50`) | ✅ Да |
| `courier_delivering` | "Курьер доставляет заказ" | Фиолетовый (`text-purple-400 bg-purple-400/20 border-purple-400/50`) | ✅ Да |
| `completed` | "Заказ завершен" | Зеленый (`text-green-400 bg-green-400/20 border-green-400/50`) | ❌ Нет |
| `cancelled` | "Отменен" | Красный (`text-red-400 bg-red-400/20 border-red-400/50`) | ❌ Нет |

### Файлы с логикой:
- `app/dashboard/client/page.tsx` (строки 169-206)
- `app/dashboard/client/orders/page.tsx` (строки 54-91)
- `app/dashboard/client/orders/[id]/page.tsx` (строки 95-110)

### Особенности:
- Видит все свои заказы (активные и завершенные)
- Может редактировать заказы только со статусом `searching_courier` и без исполнителя
- Активные заказы фильтруются: `status NOT IN ('completed', 'cancelled')`

## РОЛЬ: ВОДИТЕЛЬ (driver)

### Где отображаются статусы:
- Главная страница (`/dashboard/driver`)
- Мои заказы (`/dashboard/driver/my-orders`)

### Отображение статусов:

| Статус | Текст | Цвет | Мигает |
|--------|-------|------|--------|
| `searching_courier` | НЕ отображается (только в доступных заказах) | - | - |
| `courier_coming` | "Еду за посылкой" | Синий (`text-blue-400 bg-blue-400/20 border-blue-400/50`) | ✅ Да |
| `courier_delivering` | "Доставляю заказ" | Фиолетовый (`text-purple-400 bg-purple-400/20 border-purple-400/50`) | ✅ Да |
| `completed` | "Заказ завершен" | Зеленый (`text-green-400 bg-green-400/20 border-green-400/50`) | ❌ Нет |
| `cancelled` | "Отменен" | Красный (`text-red-400 bg-red-400/20 border-red-400/50`) | ❌ Нет |

### Файлы с логикой:
- `app/dashboard/driver/page.tsx` (строки 232-234) - встроенная логика
- `app/dashboard/driver/my-orders/page.tsx` (строки 53-86)

### Особенности:
- Видит активные заказы со статусами: `courier_coming`, `courier_delivering`
- Видит завершенные заказы: `completed`, `cancelled`
- На главной странице статусы отображаются встроенной логикой (не через функцию)
- В разделе "Мои заказы" используется функция `getStatusLabel`

### Различия в тексте:
- **Для клиента**: "Курьер едет к вам" / "Курьер доставляет заказ"
- **Для водителя**: "Еду за посылкой" / "Доставляю заказ"

## Проблемы и несоответствия:

1. **Водитель на главной странице** (`/dashboard/driver/page.tsx`):
   - Используется встроенная логика вместо функции `getStatusLabel`
   - Текст: "Еду за посылкой" / "Доставляю заказ" / "Заказ завершен"

2. **Админ** (`/dashboard/admin/orders/page.tsx`):
   - Нет цветовых индикаторов
   - Сокращенные тексты статусов
   - Нет функций форматирования

3. **Организация**:
   - Нет мигания статусов (в отличие от клиента)

4. **Карта заказов** (`components/map/OrdersMap.tsx`):
   - Собственные функции `getStatusLabel` и `getStatusColor`
   - Тексты: "Ищем курьера", "Курьер едет", "Доставляется", "Завершен", "Отменен"
