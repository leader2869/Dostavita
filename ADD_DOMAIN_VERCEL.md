# Добавление домена prosto.of.by в Vercel

## Шаг 1: Добавить домен в Vercel

1. Откройте ваш проект в Vercel Dashboard
2. Перейдите в настройки проекта: **Settings** → **Domains**
3. В поле "Domain" введите: `prosto.of.by`
4. Нажмите **Add**

## Шаг 2: Настроить DNS записи на Hoster.by

Vercel покажет вам DNS записи, которые нужно добавить. Обычно это:

### Вариант 1: Корневой домен (prosto.of.by)

**Тип A записи:**
- **Тип:** `A`
- **Имя:** `@` (или оставьте пустым для корневого домена)
- **Значение:** IP адрес от Vercel (будет показан в настройках, обычно `76.76.21.21`)
- **TTL:** `3600` (или по умолчанию)

### Вариант 2: Поддомен www (www.prosto.of.by)

**Тип CNAME записи:**
- **Тип:** `CNAME`
- **Имя:** `www`
- **Значение:** `cname.vercel-dns.com`
- **TTL:** `3600` (или по умолчанию)

## Шаг 3: Настройка на Hoster.by

1. Войдите в панель управления Hoster.by
2. Найдите раздел **DNS** или **Управление доменом**
3. Выберите домен `prosto.of.by`
4. Добавьте DNS записи, которые показал Vercel:

### Пример для корневого домена:
```
Тип: A
Имя: @
Значение: 76.76.21.21 (IP от Vercel)
TTL: 3600
```

### Пример для www:
```
Тип: CNAME
Имя: www
Значение: cname.vercel-dns.com
TTL: 3600
```

## Шаг 4: Ожидание

После добавления DNS записей:
- Vercel начнет проверку домена
- Обычно это занимает **1-24 часа**, но чаще всего **1-2 часа**
- Статус можно отслеживать в Vercel Dashboard в разделе **Domains**

## Шаг 5: Проверка

После того, как DNS записи применятся:

1. В Vercel Dashboard статус домена должен стать **Valid**
2. Откройте `https://prosto.of.by` в браузере
3. Должен открыться ваш сайт

## Важно: Настройка Supabase

После подключения домена нужно:

1. Открыть **Supabase Dashboard** → **Settings** → **API**
2. В разделе **URL Configuration** добавить в **Site URL**: `https://prosto.of.by`
3. В разделе **CORS** добавить `https://prosto.of.by` в список разрешенных доменов

## Решение проблем

### Домен не подключается
- Проверьте, что DNS записи добавлены правильно
- Убедитесь, что прошло достаточно времени (до 24 часов)
- Проверьте статус в Vercel Dashboard

### Ошибка SSL
- Vercel автоматически выдает SSL сертификат через Let's Encrypt
- Подождите несколько минут после подключения домена

### Редирект на другой домен
- Проверьте настройки редиректа в Vercel
- Убедитесь, что домен правильно настроен в Supabase

## Дополнительно

Если хотите, чтобы `www.prosto.of.by` редиректил на `prosto.of.by`:
- В Vercel Dashboard → Settings → Domains
- Настройте редирект с www на корневой домен
